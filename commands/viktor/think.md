# /viktor:think

当用户输入此命令时：

## 1. 加载 Skill

读取并严格遵循 `skills/01-brainstorming/SKILL.md`。

## 2. 需要的输入

用户在命令后附带的需求描述，例如：`/viktor:think 我想给 Todo 添加优先级功能`

$ARGUMENTS

如果 `$ARGUMENTS` 为空，回应：
> "请描述你想实现的功能或遇到的问题，例如：`/viktor:think 我想给 Todo 添加优先级功能`"

## 3. 执行过程

按照 `skills/01-brainstorming/SKILL.md` 的步骤执行：

1. **探索上下文**：优先读取 `docs/project-context.md`，不存在则扫描项目结构
2. **评估范围**：判断是否需要拆分子项目
3. **批量提问**（至多 1 轮，最多 3 个问题）：只对无法从上下文推断的关键决策一次性提问
4. **生成完整设计文档**：顶部附带「AI 假设声明」区块
5. **Spec 自审**：确认无占位符、矛盾、歧义
6. **单轮确认**：展示完整文档，用户只需指出不符的具体条目

## 4. 完成后提示

设计文档获得用户确认后输出导航卡：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ BRAINSTORM 已完成
📄 产物：docs/specs/YYYY-MM-DD--<feature>.md
──────────────────────────────
▶ 下一步：输入 /viktor:plan
  将设计文档拆解为可执行任务列表
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 5. Hard Gate

**在用户未明确确认 design.md 之前，不响应 `/viktor:plan` 或 `/viktor:code` 请求。**

提示：
> "design.md 尚未确认，请先确认设计内容再进入下一步。"
