# /viktor:context

当用户输入此命令时：

## 1. 加载 Skill

读取并严格遵循 `skills/08-context/SKILL.md`。

## 2. 前置条件

**无前置条件**，随时可用，不依赖任何其他节点或文档。

## 3. 执行过程

按照 `skills/08-context/SKILL.md` 的步骤执行：

1. **检查**：逐一检查 5 个活文档是否存在
2. **输出**：将各文件内容格式化为 5 个区块输出到对话
3. **缺失处理**：文件不存在时给出说明（建议执行 `/viktor:init`）
4. **结束提示**：输出「只读，未修改任何文件」说明

- 不生成任何文件
- 不创建 git commit
- 不修改任何现有内容
