# fe-ai-workflow 分发与团队试点文档任务列表

**日期**：2026-05-07
**关联设计**：[docs/superpowers/specs/2026-05-07-workflow-distribution-and-team-guide-design.md](../specs/2026-05-07-workflow-distribution-and-team-guide-design.md)
**总任务数**：4（P0: 3, P1: 1, P2: 0）

## 功能概述

将 `fe-ai-workflow` 作为可版本化的 git 工作流包分发到业务项目中，并提供一份面向团队试点的统一说明文档，支持 Claude Code / Codex / Cursor 三种入口同时可用。

## 技术方案

采用 `git submodule + 同步脚本` 作为安装分发方案：workflow 仓库按 tag 版本发布，业务项目通过 submodule 固定版本，再通过同步脚本把入口文件物化到项目根目录，供各 AI 工具直接读取。

## 风险标注

| 任务 | 风险类型 | 说明 | 应对策略 |
|------|---------|------|---------|
| T001 | ⚠️ 兼容性风险 | 不同业务项目的目录结构可能不同 | 同步脚本参数化源路径/目标路径，默认值保持简单 |
| T001 | ⚠️ 版本风险 | workflow 仓库与业务项目版本不同步 | 使用 tag 锁定版本，重复执行同步脚本覆盖入口文件 |
| T002 | ⚠️ 传播风险 | 文档写得过长会降低试点阅读率 | 保持单篇、结构固定、内容直接面向第一次使用 |
