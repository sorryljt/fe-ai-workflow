# CONTEXT — 项目状态快照

## 概述

读取项目的 5 个活文档，将内容格式化后输出到当前对话。
**不生成文件，不创建 commit，无副作用。** 随时可用，适合需求开始前快速回顾项目现状。

## 触发条件

以下任一情况触发本 Skill：
- 用户输入 `/viktor:context` 命令
- 用户输入自然语言意图（"看看项目现状" / "查一下现有组件" / "列出现有接口"）

## 读取文件列表

按顺序读取以下 5 个活文档：

| 文件路径 | 描述 |
|----------|------|
| `docs/project-context.md` | 项目知识地图（技术栈、目录结构、约定） |
| `docs/component-catalog.md` | 现有组件目录 |
| `docs/api-catalog.md` | 现有 API 接口目录 |
| `docs/architecture.md` | 架构决策速览 |
| `docs/adrs/README.md` | ADR 索引（所有架构决策记录） |

## 执行步骤

### 第 1 步：检查文件存在情况

逐一检查 5 个文件是否存在，记录状态（存在 / 缺失）。

### 第 2 步：格式化输出

按以下格式输出到对话（缺失的文件用说明替代，不报错）：

### 第 3 步：文件缺失处理

对于任何缺失的文件，在对应区块输出：

- `docs/project-context.md` 缺失：
  > 📭 项目知识地图尚未生成，建议执行 `/viktor:init` 扫描项目并初始化活文档。

- 其余活文档缺失：
  > 📭 此文档尚未初始化，建议执行 `/viktor:init` 生成活文档骨架。

- `docs/adrs/README.md` 缺失：
  > 📭 ADR 索引尚未创建，建议执行 `/viktor:init` 生成活文档骨架。

### 第 4 步：输出结束提示

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 项目快照输出完成（只读，未修改任何文件）
💡 如需开始新需求，输入 /viktor:think <需求描述>
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 约束

- **禁止**生成任何文件
- **禁止**创建 git commit
- **禁止**修改任何活文档内容
- 若活文档内容过长，输出核心表格或关键章节，并注明「完整内容见 [文件路径]」

## 验证标准

CONTEXT 成功执行的标志：
- [ ] 输出包含 5 个区块（缺失文件有说明替代）
- [ ] 未生成任何新文件
- [ ] 未创建任何 git commit
- [ ] 输出格式清晰，区块间有分隔线
